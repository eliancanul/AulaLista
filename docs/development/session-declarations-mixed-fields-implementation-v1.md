# Closed mixed-field evidence implementation v1

This detached opt-in is separate from the default literal matcher, production
interpreter, SEP identity, editorial approval and the scope auditor. The
source-only contract and fixture were committed as `01aec01e33144a0a835d99ec1d1b2985be210b0d`
before this runtime was written. Existing references and scorers are unchanged.

`extract_declarations(..., mixed_fields=True)` runs the ordinary extractor first,
then `scripts/mixed_field_recovery.py` can append one whole exact `value`
SourceReference to an existing `kind=null`, `abstained/combined_label` record.
Every pre-existing key, evidence reference, identifier, unit and claim is kept.
Other records, including incidental mentions inside the mixed value, remain
visible. No typed declaration or AtomicClaim is generated. Existing values are
idempotently preserved. The default and explicit `mixed_fields=False` return the
prior output exactly, without a new sidecar or provider invocation.

The optional `mixed_field_recovery` sidecar contains the method version, exact
label/value UTF-8 hashes, same-page closing-heading evidence and original
metadata context. Those references attest literal provenance and bounded
source grammar, not type or membership. The source scanner is reused without
changes only for existing session resets and closing headings. No new scope
identity is assigned by recovery, including cross-page metadata continuation.

## Preserved conservative omission

The initial 70-document source-only fixture has 24 recovery opportunities,
48 rejection challenges and two typed controls. The initial implementation
recovers 23 of 24 exact values with zero recovery outside that reference. One
source-side genuine-session-reset opportunity remains omitted: the inherited
example paragraph has no blank closing paragraph. The new route retains the
existing `example_context` guard rather than weakening it to earn the remaining
point. The independently frozen reference is not edited; tests explicitly retain
both the denominator and the omission. This is 23/24 literal recovery on exposed
synthetic development, not global or semantic accuracy.

## Interpretation boundary

Mixed values stay mixed. A list marker, nominal phrase or learning verb cannot
promote a substring to an explicitly source-labelled contenido/PDA. Codes remain
literal unresolved expressions. A generic phrase is still a generic phrase.
Physical unit metadata does not become a newly established scope proof merely
because its value is now present. Existing typed and strict-session scores must
be reported independently and remain unchanged by this option.

The separately versioned `mixed_audit` hook can add a reviewed offline replay
sidecar after exact recovery. It runs before the legacy scope audit and receives
the unmodified base output plus recovery ledger. Replay success means transport,
identity, exhaustive source coverage and schema validation only; it is never
semantic acceptance. Real calls, retries, expansion and production application
are outside both modules and require a separately frozen development protocol.

## Frozen metadata supplement and measured limits

The split-metadata source-only supplement was committed as `24e2946` before
its interpretation was added. It allows a literal `Tema de la` suffix inside
an already admitted dated-session anchor to continue as `sesión:` on the next
line, and a bounded `Tiempo:` transition at the end of a wrapped thematic value.
Original anchors and all source spans remain unchanged. Unknown metadata labels,
extra title prefixes, missing colons, controls and unsafe context still fail.

Of its eight literal opportunities, four are recovered exactly. Four remain
omissions because the unchanged scanner admits no dated session in those
synthetic sources; some have no corroborating activity moment. The new route
cannot manufacture a reset or unit. All sixteen rejection challenges are
preserved. Across both frozen fixtures, the observed evidence-only recovery is
27/32, with no false new values among the 64 rejection opportunities. Existing
raw default emissions remain visible and are not described as a global perfect
precision result.

On the exposed five-PDF development window, physical pages 7–12, all 15 complete
mixed fields are recovered exactly. The immutable broad inventory remains 43:
whole-field literal recovery increases 21/43 to 36/43. Typed literal recovery
remains 21/23 and deterministic typed joint recovery remains 16/23. Existing
physical-unit metadata is 31/43; the 30/43 literal-plus-metadata intersection is
not semantic scope proof or internal curricular interpretation. No old reference,
scorer, denominator, frozen source or prior output was changed to obtain this
result. Local code expressions, generic descriptions and structurally mixed
blocks remain untyped. This does not establish 90% interpretation accuracy.
